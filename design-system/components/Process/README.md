# Quy trình

Nguồn: CSS `.editorial-strip`, `.editorial-item`; spec [ba trang con R8](../../../docs/specs/detail-pages.md#r8-dải-quy-trình-portal-loại-hình).

Năm bước Khảo sát, Tư vấn, Sản xuất, Lắp đặt, Hậu mãi, một dải ảnh dùng chung cho Residential, Commercial, About.

## Dải ảnh

- `section.editorial-strip.detail-process-editorial`: năm `editorial-item` một hàng, mỗi item ảnh tỷ lệ
  `2048 / 3072` cắt cao 208px, tiêu đề chữ hoa 600 (20px ở 1440, 16px ở 390), đoạn 16px/24.
- Số bước lớn màu `line` nằm sau chữ, góc phải dưới.
- Tiêu đề bước đầu màu `blue`, bước cuối `orange`, còn lại `ink`.
- Điện thoại: hàng cuộn ngang, item 280.8px.

## Chú thích thuật ngữ

- **Editorial strip**: dải item ảnh và chữ xếp như trang tạp chí.
